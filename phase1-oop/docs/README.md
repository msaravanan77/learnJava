## 💡 Tips for C Programmers

These documents are specifically designed with C programmers in mind:
- Every Java concept is compared to C equivalents
- Highlights what's different and why
- Explains the mental model shift from procedural to OOP

Key comparisons covered:
- C structs → Java classes
- Function pointers → Polymorphism
- Manual memory → Garbage collection
- Composition in C → Inheritance + Composition in Java
