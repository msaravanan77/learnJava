# Archive: PAM-Specific Examples

This folder contains the original PAM (Privileged Access Management) and security-focused examples that were created for professionals in the cybersecurity domain.

## Contents

- **HANDSON_ROADMAP.md** - Original roadmap with PAM/security examples
- **week1-tensors/** - Security-focused tensor examples
  - day1_tensor_basics.py - Failed login analysis
  - day2_password_analysis.py - Password strength analyzer

## Why Archived?

These examples are excellent for security professionals but too domain-specific for a general AI/ML fundamentals course. They've been replaced with universal examples that anyone can relate to:
- E-commerce sales patterns
- Weather data analysis
- Movie ratings
- Website traffic
- etc.

## Still Useful If:

- You work in cybersecurity/PAM
- You want security-specific AI/ML applications
- You're interested in anomaly detection in access logs

Feel free to use these as reference for security-domain ML projects!
